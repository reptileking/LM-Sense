`configs/structural.yaml`. Token ids live in the reserved range `0xFFC00000`–`0xFFFFFFFF`
(top 4,096 lemma slots of the 22 + 10-bit layout). Each category owns one slot (1,024 ids);
ids are permanent and append-only.

## Conventions

* **Order inside a word**: `[case] [variant] SENSE [morph features…]`, e.g. `<case:cap> run <morph:PST>` → "Ran".
* **Morphology** uses UniMorph feature names; features are atomic tokens emitted after the sense token, in schema order (tense/aspect, mood, voice, person, number, degree, finiteness, case, gender, polarity). Unmarked = the lemma form.
* **Byte fallback**: `<byte:bytes_start>` UTF-8 bytes `<byte:bytes_end>`; a byte span is one orthographic word (spacing rules apply around it).
* **Numbers** are digit tokens with punctuation tokens for separators: 3.14 → `<digit:3> <punct:.> <digit:1> <digit:4>`.
* **Spacing** defaults to one space between words and none before closing punctuation; `<space:…>` tokens override it.
